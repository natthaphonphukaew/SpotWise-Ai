# LLM output cache

ผลจาก Gemini ที่ผ่าน zod แล้ว แยกโฟลเดอร์ตามงาน (`business-profile/` ฯลฯ) ชื่อไฟล์คือ hash ของ prompt + input + model

- ตอน dev ที่มี `GEMINI_API_KEY` ทุกผลลัพธ์ใหม่จะถูกเขียนที่นี่อัตโนมัติ
- **commit โฟลเดอร์นี้** เพื่อให้เว็บที่ deploy แล้วตอบได้โดยไม่เรียก API (โหมดเดโม)
- ห้ามแก้ไฟล์ในนี้ด้วยมือ ถ้าจะสร้างใหม่ให้ลบไฟล์แล้วเรียกใหม่
