## ชุดตัดสินจริง: `label_sample.csv`

รายการ 100 จุดที่ **กฎกับ AI ตัดสินไม่ตรงกัน** (60 จุดเกี่ยวกับร้านอาหาร/เครื่องดื่ม) ให้กรอกคอลัมน์ `correct_group` ด้วยความรู้จริงของย่าน หรือดูหน้าร้านใน Street View หรือรีวิว

ค่าที่ใช้ได้ใน `correct_group`:
`bubble_tea` `coffee` `drink_dessert` `food` `convenience` `education` `dormitory` `market` `office` `health` `leisure` `retail` `other`

ถ้าไม่แน่ใจให้เว้นว่างแล้วเขียนเหตุผลใน `note` จุดที่เว้นว่างจะไม่ถูกนับ
