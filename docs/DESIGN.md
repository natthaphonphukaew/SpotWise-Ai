## 1. Concept: "รายงานสำรวจทำเล" (Field Survey Report)

ผสม 3 โลกเข้าด้วยกัน:
1. **สมุดสนามของนักสำรวจ/นักทำแผนที่**: กระดาษสีครีม เส้นบาง พิกัด ตัวเลข mono
2. **ผังเมืองรวมของไทย**: ใช้สีตามความหมายของสัญลักษณ์ผังเมือง (คนไทยหลายคนคุ้นตา และ**ไม่มีใครเอามาทำ UI**)
3. **งานข่าวเชิงข้อมูล (data journalism)**: หัวข้อตัวมีเชิง เชิงอรรถ [1][2] ทุกตัวเลขมีที่มา

ความหมายที่สื่อ: "เราไปเดินดูมาแล้ว และบอกได้ว่าทุกตัวเลขมาจากไหน"

### Signature idea: **ความไม่แน่นอนมองเห็นได้**
- มี 3 สถานะ: **ประมาณการ** = ลายเส้นทแยง (hatch) · **ข้อมูลเปิด** = ทึบสีอ่อน (`--ink-3`) · **สำรวจจริง** = ทึบสีเข้ม (`--ink`)
- ลายทแยงมีความหมายเดียวคือ "ค่าประมาณ" ห้ามใช้เพื่อความสวยงาม
- เมื่อผู้ใช้ทำ Field Mode ลายทแยงจะค่อยๆ เติมเป็นสีทึบ (animation ~600ms)
- Confidence เพิ่มขึ้นไม่ได้แปลว่าคะแนนต้องเพิ่ม (ลงพื้นที่แล้วอาจเจอคู่แข่งที่ข้อมูลเปิดไม่มี) ต้องโชว์ความซื่อตรงนี้ในเดโม
- ได้แรงบันดาลใจจากลายในผังเมืองจริง (เช่น เขียวลายขาว) และเป็นภาษาภาพเดียวที่ใช้ทั้งแอป ทั้งในแผนที่ แท่งคะแนน และกราฟเงินสด

## 3. Color Tokens

### 3.1 UI (Light = โหมดหลัก)

| Token | Hex | ใช้กับ |
|---|---|---|
| `--paper` | `#F4F1EA` | พื้นหลังหลัก |
| `--paper-2` | `#EAE5D9` | แผง/คอลัมน์รายงาน |
| `--ink` | `#1C1B18` | ตัวอักษรหลัก, ปุ่มหลัก, หมุดทำเล |
| `--ink-2` | `#5F5D55` | ตัวอักษรรอง |
| `--ink-3` | `#8E8B80` | label เล็ก, พิกัด |
| `--rule` | `#D6D0C2` | เส้นบาง 1px |
| `--accent` | `#E8620C` | **ใช้น้อยมาก**: ทำเลที่เลือก, focus, Confidence ที่เพิ่มขึ้น |

### 3.2 Data (ตามความหมายของผังเมือง)

| ความหมายในแอป | สีผังเมืองต้นแบบ | Hex (ปรับให้หม่นลงให้เข้ากับกระดาษ) |

| ความหนาแน่นประชากร ต่ำ → กลาง → สูง | เหลือง → ส้ม → น้ำตาล (ที่อยู่อาศัย) | `#F0D27A` → `#E9A35E` → `#9C6A3E` |
| **คู่แข่ง** | แดง (พาณิชยกรรม) | `#C2373D` |
| สถานศึกษา (เกื้อหนุน) | มะกอก (สถาบันการศึกษา) | `#7C8A3A` |

## 4. Typography (Google Fonts ฟรีทั้งหมด รองรับไทย)

| บทบาท | ฟอนต์ | เหตุผล |
|---|---|---|
| Display: หัวข้อ, ตัวเลขคะแนนใหญ่ | **Trirong** (สำรอง: Noto Serif Thai) | serif ไทยแบบมีหัว ให้อารมณ์รายงาน/สิ่งพิมพ์ ต่างจากเว็บ AI ทั่วไปทันที |
| UI / เนื้อหา | **Anuphan** | loopless อ่านง่าย พัฒนาจาก IBM Plex (Cadson Demak) WeVis ก็ใช้ |
| ตัวเลข / พิกัด / label / evidence ID | **IBM Plex Mono** | DNA เดียวกับ Anuphan ใช้คู่กันแล้วกลมกลืน Punchup ก็ใช้ · Plex Mono ไม่มีอักษรไทย จึงต้องตั้ง stack เป็น `"IBM Plex Mono","Anuphan",monospace` |

**ห้ามใช้:** Kanit, Prompt, Mitr, Sarabun (ดูเป็นเอกสารราชการ), Inter, Poppins

**กฎสำหรับภาษาไทย:**
- line-height ของเนื้อหาไทย 1.6–1.75 (สระบน/ล่างต้องไม่ชนกัน)
- **ห้าม** ใส่ letter-spacing หรือ uppercase tracking กับข้อความไทย (ทำได้เฉพาะ label อังกฤษที่เป็น mono)
- ตัวเลขใช้ `font-variant-numeric: tabular-nums`
- Scale: 12 / 14 / 16 / 20 / 28 / 40 / 64 / 96 (96 ใช้กับคะแนนใหญ่เท่านั้น)

## 5. Layout

```
┌───────────────────────────────────────────────────────────────┐
│ SPOTWISE · รายงานสำรวจ No.001 · บางมด    LAT 13.6512 LON 100.4943 Z15 · CONF 62% │  ← แถบ mono
├──────────────────┬────────────────────────────────────────────┤
│ คอลัมน์รายงาน     │                                            │
│ (≈420px, paper-2)│        แผนที่เต็มพื้นที่                        │
│ หัวข้อ serif      │   หมุดทำเล A/B/C (ทรงหมุดสำรวจ)               │
│ คะแนน 96px       │   catchment = เส้นประ                          │
│ แท่ง 5 มิติ       │   คู่แข่ง = จุดแดง · เกื้อหนุน = มะกอก/น้ำเงิน      │
│ เชิงอรรถ [1][2]   │   callout แบบเส้นโยง + label mono              │
├──────────────────┴────────────────────────────────────────────┤
│ แถบเวลา  06 ─── 09 ─── 12 ─── 15 ─── 18 ─── 21   (activity)   │
└───────────────────────────────────────────────────────────────┘
```

- Desktop: แผนที่ + คอลัมน์รายงานเหมือนเอกสารวางข้างแผนที่ **ไม่ใช่ dashboard ที่เป็นกริดการ์ด**
- Mobile (Field Mode): จอเดียว ปุ่มนับคนกินพื้นที่ ≥50% ของจอ ตัวเลข mono ใหญ่ contrast สูงเพื่อใช้กลางแดด และสั่นเครื่องด้วย `navigator.vibrate` ทุกครั้งที่กด
- หน้าแรก = **ปกรายงาน** ("รายงานสำรวจทำเล No.001 · บางมด" + ช่องพิมพ์คอนเซ็ปต์) ไม่ใช่ hero แบบ landing page

## 6. Components

| Component | ทำแบบนี้ | ไม่ทำแบบนี้ |
|---|---|---|
| คะแนนรวม | ตัวเลข serif 96px + "/100" mono เล็ก | gauge วงกลม, donut |
| คะแนนรายมิติ | แท่งแนวนอนแบบไม้บรรทัดมีขีด (tick) · ทึบ = จริง · ลายทแยง = ประมาณ | progress bar มนๆ ไล่สี |
| Confidence | ตัวเลข % mono + ลายทแยงบนแท่ง | badge สีเขียว/แดงที่ไม่มีคำอธิบาย |
| Evidence | เชิงอรรถ `[3]` mono → drawer: แหล่ง, วันที่ดึงข้อมูล, license, ข้อจำกัด | tooltip ที่บอกแค่ว่า "AI วิเคราะห์" |
| หมุดทำเล | ทรงหมุดสำรวจ/ธง สีหมึก ตัวอักษร A B C | หมุด Google สีแดง |
| ตาราง Compare | เส้นบาง 1px · tabular nums · ไฮไลต์ค่าที่ดีที่สุดด้วยเส้นใต้ accent | การ์ดเงาเรียงกัน |
| ปุ่ม | สี่เหลี่ยม radius 2–4px · พื้นหมึก ตัวอักษรกระดาษ · ไม่มีเงา | gradient, pill, glow |
| ผลจาก AI | ป้าย "วิเคราะห์จาก 14 แหล่งอ้างอิง · 17 ต.ค. 69" · แยกหัวข้อ ข้อเท็จจริง / สมมติฐาน / ข้อเสนอแนะ | ✨ sparkle, "AI-powered", ฟองแชต |
| Devil's Advocate | 2 คอลัมน์เหมือนบันทึกการประชุม ฝ่ายหนุน / ฝ่ายค้าน + คำตัดสินด้านล่าง | ฟองแชต + avatar หุ่นยนต์ |
| กราฟเงินสด 12 เดือน | แท่งรายเดือน · ช่วงปิดเทอมเป็นแถบพื้น `--paper-2` + label "ปิดภาค" · เดือนขาดทุนเป็นแท่งโปร่งพร้อมตัวเลขในวงเล็บแบบงานบัญชี · บอกว่า "ประมาณการ" ที่หัวกราฟครั้งเดียว | กราฟเส้นไล่สีพื้นหลัง, แท่งแดง |
| ไอคอน | Phosphor (น้ำหนัก light/regular) ใช้เท่าที่จำเป็น | emoji, Lucide ทุกจุดแบบ shadcn default |

> ใช้ shadcn/ui หรือ Radix เป็นโครงได้ แต่**ต้องเขียน token ทับทั้งหมด** (radius, เงา, สี, ฟอนต์) ห้ามปล่อยหน้าตา default

## 7. Map Style

- basemap: Protomaps/OpenFreeMap แล้วปรับสีเอง โดยให้แผ่นดินเป็น `--paper` ถนนสีเทาอุ่น `#DDD6C8`/`#CFC7B6` น้ำสีเทาฟ้าหม่น `#C9D3D6` และอาคารเป็น outline บางๆ
- label ของ basemap ให้น้อยที่สุด ชื่อสถานที่สำคัญของเรา (มจธ., ตลาดบางมด) ให้วาดเป็น **HTML marker ด้วย Anuphan** เพราะ MapLibre อาจวางสระ/วรรณยุกต์ไทยไม่สวย (ต้องทดสอบในสัปดาห์ที่ 1)
- catchment: เส้นประหมึก + พื้นโปร่งลายทแยงจางๆ
- ต้องแสดง attribution: © OpenStreetMap contributors, Overture Maps

## 8. Motion

- ระยะเวลา 150–250ms, ease-out · map `flyTo` ~1.2s
- ตัวเลขคะแนนเปลี่ยนแบบ tick (นับขึ้น/ลง) เมื่อปรับ slider
- ลายทแยงเติมเป็นสีทึบ 600ms เมื่อได้ข้อมูลจริงจาก Field Mode ← moment สำคัญของเดโม
- เคารพ `prefers-reduced-motion`

---

## 9. Copywriting

- ภาษาไทยธรรมดา ตรง เฉพาะเจาะจง: "ในระยะเดิน 5 นาที มีร้านชาไข่มุก 4 ร้าน [2]" ไม่ใช่ "AI ของเราวิเคราะห์อย่างชาญฉลาด"
- ทุกตัวเลขต้องมีหน่วยและที่มา
- ระบุให้ชัดว่าค่าไหนประมาณ: "≈ 180–260 คน/วัน (ประมาณการ)"

## 10. Anti-Slop Checklist (ตรวจก่อน merge ทุกหน้า)

- [ ] ไม่มี gradient ม่วง/ฟ้า, glassmorphism, glow
- [ ] ไม่มี emoji หรือ ✨ ใน UI
- [ ] ไม่มีการ์ดมุมมน + เงาเรียงเป็นกริด
- [ ] ไม่ใช้ Inter, Poppins, Kanit, Prompt
- [ ] ไม่มี hero กลางจอแบบ "Unlock the power of AI"
- [ ] ไม่มี donut/gauge chart
- [ ] ตัวเลขทุกตัวมีหน่วย + ที่มา + บอกว่าจริงหรือประมาณ
- [ ] ข้อความไทยไม่มี letter-spacing และ line-height ≥ 1.6
- [ ] accent สีส้มปรากฏไม่เกิน 1–2 จุดต่อจอ
- [ ] ดูดีทั้งบนจอโปรเจกเตอร์ (contrast) และมือถือกลางแดด
